# DVM-GPIB-Scanner

A collection of Python tools for automated measurement and data acquisition from Digital Multimeters (DMMs) via GPIB interface. These programs support multiple DMM models including Keithley 2100, Iwatsu VOAC 7513, and Prema 6000, with real-time plotting and CSV data logging capabilities.

## 📋 Overview

This repository contains several specialized programs for different measurement scenarios:

1. **StahlRatioScanner.py** - Basic ratio measurement program for Keithley 2100
2. **StahlRatioScanner_printer.py** - CSV data plotter and visualization tool
3. **StahlRatioScannerPyQtGraph.py** - Optimized version for long measurements with PyQtGraph
4. **DMM-GPIB-Scanner.py** - Most versatile program supporting multiple DMM models

---

## 🔧 Programs

### 1. StahlRatioScanner.py

#### Keithley 2100 Ratio Measurement Program

The primary ratio measurement tool for Keithley 2100 DMM. This program performs continuous ratio measurements with:
- **Main channel**: 100V (fixed)
- **Ratio input pair**: Auto (auto-ranging)
- **Display**: Deviation in ppm (parts per million)
- Real-time matplotlib plotting
- Automatic CSV data logging

#### Usage

```bash
# Default: measure until tomorrow 8 AM
python StahlRatioScanner.py

# Measure for specific duration
python StahlRatioScanner.py 10m    # 10 minutes
python StahlRatioScanner.py 2h     # 2 hours
python StahlRatioScanner.py 1d      # 1 day

# Measure until specific date/time
python StahlRatioScanner.py "2025-12-01 09:10:00"

# Show help
python StahlRatioScanner.py -h
```

#### Features of StahlRatioScanner
- Real-time animated plotting with matplotlib
- Moving average and total average calculations
- Automatic CSV file generation with timestamps
- Flexible duration/time specification
- Deviation display in parts per million (ppm)

### 2. StahlRatioScanner_printer.py

#### CSV Data Plotter and Visualization Tool

A companion program to visualize and print measurement data from CSV files generated by the measurement programs. This tool:
- Reads CSV files with measurement data
- Creates publication-quality plots
- Supports multiple time axes for detailed analysis
- Generates high-resolution output images

#### Usage for StahlRatioScanner_printer

```bash
python StahlRatioScanner_printer.py
```

The program will:
1. Automatically detect CSV files in the current directory
2. Show a file selection dialog (if multiple files found)
3. Generate plots with the same format as live measurements
4. Save high-quality output images

#### Features of StahlRatioScanner_printer
- Interactive file selection dialog
- Automatic CSV parsing with comment support
- Multiple plot views (main figure + subplots)
- Professional formatting with proper time axes
- PNG output with high resolution

**Note**: This printer script works with CSV files from:
- `StahlRatioScanner.py`
- `StahlRatioScannerPyQtGraph.py`
- `DMM-GPIB-Scanner.py` (for Keithley 2100 ratio measurements)

### 3. StahlRatioScannerPyQtGraph.py

#### Optimized Version for Long Measurements

An optimized version of the ratio scanner using PyQtGraph instead of matplotlib for better performance during extended measurement sessions. Ideal for:
- Long-duration measurements (hours to days)
- High-frequency data acquisition
- Reduced memory usage
- Smoother real-time updates

#### Usage for StahlRatioScannerPyQtGraph

Same command-line interface as `StahlRatioScanner.py`:

```bash
# Default: measure until tomorrow 8 AM
python StahlRatioScannerPyQtGraph.py

# Measure for specific duration
python StahlRatioScannerPyQtGraph.py 10m
python StahlRatioScannerPyQtGraph.py 2h
python StahlRatioScannerPyQtGraph.py "2025-12-01 09:10:00"
```

#### Features of StahlRatioScannerPyQtGraph
- PyQtGraph-based plotting for better performance
- Optimized for long measurement sessions
- Lower memory footprint
- Smooth real-time updates
- Same CSV output format as `StahlRatioScanner.py`

**Printer Support**: Use `StahlRatioScanner_printer.py` to visualize data from this program's CSV files.

### 4. DMM-GPIB-Scanner.py

#### Most Versatile Multi-DMM Scanner

The most comprehensive program in this collection, supporting multiple DMM models with automatic instrument detection. This versatile tool can work with:

#### Supported Instruments for DMM-GPIB-Scanner

**Legacy Instruments (via GPIB-USB adapter):**
- **Iwatsu VOAC 7513** - DC voltage measurements
- **Prema 6000** - DC voltage measurements
- Easily extensible architecture for additional legacy instruments

**Modern Instruments (USB/GPIB):**
- **Keithley 2100** - Ratio measurements
  - Main channel: 100V (fixed)
  - Ratio input pair: Auto (auto-ranging)
  - Deviation displayed in ppm

#### Usage for DMM-GPIB-Scanner

```bash
# Auto-detect instrument (default: until tomorrow 8 AM)
python DMM-GPIB-Scanner.py

# Auto-detect with specific duration
python DMM-GPIB-Scanner.py 10m
python DMM-GPIB-Scanner.py 2h
python DMM-GPIB-Scanner.py "2025-12-01 09:10:00"

# Force legacy mode for legacy instruments
python DMM-GPIB-Scanner.py legacy 10m
python DMM-GPIB-Scanner.py legacy 2h

# Show help
python DMM-GPIB-Scanner.py -h
```

#### Features of DMM-GPIB-Scanner
- **Automatic instrument detection** - Identifies legacy vs modern instruments
- **Multi-instrument support** - Works with three different DMM types
- **Flexible measurement modes** - DC volts for legacy, ratio for Keithley 2100
- **Real-time plotting** - Live visualization during measurements
- **CSV logging** - Automatic data storage with timestamps
- **Modular architecture** - Easy to extend with new instrument classes

**Printer Support**: For Keithley 2100 ratio measurements, use `StahlRatioScanner_printer.py` to create fine-printed plots with three time axes for detailed analysis.

## 🔍 Measurement Data

All programs generate CSV files with the following structure:
- Timestamp (YYYY-MM-DD HH:MM:SS)
- Measurement value
- Moving average
- Total average
- Optional comments in header

CSV files are automatically named with timestamps for easy identification.
